# LeanType Chirp v1.0.10

## What's New

- One release download: Standard APK.
- Release signing now fails fast instead of producing an unsigned APK.
- Standard release workflow builds and publishes only Standard.

## Download

`1-LeanType-Chirp_1.0.10-standard-release.apk`

Includes Cloud AI, Handwrite, and Chirp. Requires Internet permission.

Install with Android package installer or:

```bash
adb install -r 1-LeanType-Chirp_1.0.10-standard-release.apk
```

Do not install unsigned or incomplete APK files. Android rejects them with `INSTALL_PARSE_FAILED_NO_CERTIFICATES`.
